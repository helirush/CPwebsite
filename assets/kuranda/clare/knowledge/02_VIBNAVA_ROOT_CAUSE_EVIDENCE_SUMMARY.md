- How to use this workbook
- **1:** Start with Level 1 mechanisms, not diagnoses.
- **2:** Use the Root-Link Evidence column to explain why a mechanism matters.
- **3:** Use VIBNAVA Evidence Status and Confidence Grade to control claim strength.
- **4:** Follow Reference IDs to the source list; add new papers without rewriting the taxonomy.
- Scope note: This is an initial evidence architecture, not a clinical-claims dossier. The database deliberately separates established upstream biology from evidence that the specific VIBNAVA device, frequency, amplitude, tissue coupling, duration, and sequence produce the proposed effect.
